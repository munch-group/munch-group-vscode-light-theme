# Munch Group Light Theme

A calm, warm light theme for VS Code, inspired by the built-in Light Modern theme.

## Installation

Install from the Visual Studio Code Marketplace, or from the command line:

```
code --install-extension munch-group.munch-group-light-theme
```

Then select the theme with **Cmd+K Cmd+T** (macOS) or **Ctrl+K Ctrl+T** (Windows/Linux) and choose **Munch Group Light**.
